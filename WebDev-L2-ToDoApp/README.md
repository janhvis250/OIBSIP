# TaskFlow - To-Do Web App

A modern and responsive To-Do Web App created as part of the OIBSIP Web Development & Designing Internship.

## 📌 Project Overview

TaskFlow is a simple productivity application that helps users organize their daily tasks.

Users can add tasks, mark them as completed, edit existing tasks, delete tasks, and keep their tasks saved using browser localStorage.

The project uses a clean dark interface with a premium glassmorphism-inspired design.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Move completed tasks to the Completed section
- Edit tasks inline
- Delete tasks
- Pending task count
- Completed task count
- Total task count
- Task creation timestamp
- Browser localStorage support
- Tasks remain available after refreshing the page
- Empty-state messages
- Enter key support for adding tasks
- Responsive design
- Premium dark-themed interface
- Smooth hover and task animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Google Fonts
