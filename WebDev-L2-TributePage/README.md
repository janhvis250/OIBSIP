# Steve Jobs Tribute Page

A responsive and visually polished tribute page dedicated to Steve Jobs, created as part of the OIBSIP Web Development & Designing Internship.

## 📌 Project Overview

This project presents the life, journey, achievements, and legacy of Steve Jobs through a modern dark-themed tribute website.

The page focuses on clean typography, minimal design, responsive layouts, subtle animations, and an engaging user experience.

## ✨ Features

- Premium dark-themed UI
- Responsive design for desktop, tablet, and mobile
- Steve Jobs hero section with prominent image
- About section
- Career timeline
- Inspirational quote section
- Legacy section
- Smooth scrolling navigation
- Scroll reveal animations
- Navbar scroll effect
- Image hover effect
- Glassmorphism-inspired design
- Modern typography using Google Fonts
- Custom scrollbar
- Mobile-friendly timeline layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
