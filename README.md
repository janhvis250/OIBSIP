# OIBSIP - Web Development & Designing Internship

This repository contains my project submissions for the **Oasis Infobyte Web Development & Designing Internship**.

## 📌 Internship Level

**Level 2 - Web Development & Designing**

## 🚀 Projects

### 1. Calculator
A responsive calculator built using HTML, CSS and JavaScript.

**Features:**
- Basic arithmetic operations
- Decimal calculations
- Operator chaining
- Clear and delete functionality
- Division-by-zero handling
- Responsive design

### 2. Steve Jobs Tribute Page
A responsive tribute webpage dedicated to Steve Jobs.

**Features:**
- Hero section
- Biography
- Timeline
- Key achievements
- Inspirational quote
- Responsive design

### 3. To-Do Web App
A task management web application for organizing daily tasks.

**Features:**
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Pending and completed sections
- Task counters
- LocalStorage
- Responsive design

### 4. Login Authentication System
A frontend authentication system with registration and login functionality.

**Features:**
- User registration
- Password validation
- Duplicate email checking
- SHA-256 password hashing
- Login authentication
- Protected dashboard
- Logout
- LocalStorage session
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API
- LocalStorage
