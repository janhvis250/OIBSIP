# 🧮 OIBSIP Calculator

A responsive and user-friendly calculator built as part of the **Oasis Infobyte Web Development & Designing Internship — Level 2, Task 1**.

The calculator performs basic arithmetic operations and includes input validation, error handling, operator chaining, and keyboard support.

---

## 📌 Project Overview

This project is a browser-based calculator developed using **HTML5, CSS3, and Vanilla JavaScript**.

The main objective is to create a functional calculator with a clean and responsive interface while implementing the calculation logic without using JavaScript's `eval()` function.

---

## ✨ Features

- Basic arithmetic operations
  - Addition (+)
  - Subtraction (−)
  - Multiplication (×)
  - Division (÷)
- Numeric buttons from 0–9
- Decimal number support
- Clear button
- Backspace button
- Equals button
- Operator chaining
- Correct mathematical operator precedence
- Division-by-zero error handling
- Decimal input validation
- Keyboard support
- Responsive design for mobile and desktop screens
- CSS Grid-based calculator button layout
- No inline `onclick` attributes
- Uses JavaScript `addEventListener()` for interactions
- Does not use `eval()`

---

## 🛠️ Technologies Used

- **HTML5** — Structure of the calculator
- **CSS3** — Styling, responsive design, and CSS Grid layout
- **JavaScript (Vanilla)** — Calculator functionality and logic
